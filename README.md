# 3C — Campus Care & Connect 🛡️

> **"Help exists around you."**
> A confidential, living campus support ecosystem designed for student mental wellbeing, anti-ragging protection, medical triage, and 24/7 student safety.

---

## ✨ Features

- **🌐 09 — Interactive 3D Digital Twin**:
  - Live 3D isometric campus platform featuring real-time buildings: *Medical Centre, Safe Space, Security Command, Counselling Hub, Student Hub, Hostels*.
  - Layer-switching filters: `ALL`, `MEDICAL`, `WELLBEING`, `SAFETY`, `PEER HELP`, `GIRLS SUPPORT`.
  - Interactive inspection drawer with live emergency response times, direct extension hotlines, and instant discreet contact.
  - Interactive camera rotation with inertia and starfield constellation.

- **🔒 01 — Protected Space ("You are in control")**:
  - **Three Confidential Doors**:
    1. **I NEED SUPPORT**: Real-time encrypted confidential live chat simulator with trained counselors and peer listeners.
    2. **I WANT TO REPORT**: Anonymous or formal incident intake wizard with cryptographic tracking codes (`3C-INC-XXXXX`).
    3. **I'M NOT SURE**: Guided empathetic navigator helping students clarify distress with zero pressure or labels.
  - Core Privacy Pillars: *Talk privately*, *Stay anonymous where available*, *Escalate when necessary*.

- **🌱 07 — Counselling ("A quiet hour, on your terms")**:
  - Discreet timeline slot picker (`10:00`, `11:00`, `15:00`, `17:00`, `19:30`).
  - One-click confidential booking with anonymous passkey (`3C-QH-XXXX`), requiring no sign-in or attendance records.

- **🚨 Campus Pulse — LIVE**:
  - Real-time status indicators for Medical triage, open Counselling slots, nearby Peer Helpers, and Campus Security Patrol.

- **⚡ Emergency SOS & Safety Suite**:
  - Dual triggers: Sticky header button + persistent bottom-right pulsing floating SOS pill.
  - **1-Tap Silent Security Patrol Dispatch** with live quadrangle location locking.
  - **Direct Ambulance / Medical Trauma Unit alert**.
  - **Simulated "Fake Incoming Call"**: Rings your device with a realistic incoming call screen so you can safely excuse yourself from uncomfortable or threatening situations.
  - **Quick Escape Mode**: Press <kbd>ESC</kbd> or click Quick Escape at any moment to immediately camouflage the screen to Wikipedia.
  - **Private Stealth Mode**: Invert theme to subtle dark stealth camouflage and silence all visible identifiers.

## 🚀 Quick Start (Push to GitHub in 3 Steps)

### Step 1: Create a new repository on GitHub
1. Go to [github.com/new](https://github.com/new).
2. Repository name: `3c` (or `3c-campus-care`).
3. Set visibility to **Public** or **Private**.
4. Leave "Add README", ".gitignore", and license **unchecked** (we already created them for you).
5. Click **Create repository**.

### Step 2: Push your code
Run the following commands in your terminal inside this folder:

```bash
# Ensure you are in the 3c directory
git add .
git commit -m "feat: complete 3C campus care & connect frontend"
git branch -M main
git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```

### Step 3: Enable Free GitHub Pages Hosting (Optional)
1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
3. Your website will be live worldwide in ~60 seconds!

## 🛠️ Tech Stack & Zero-Dependency Design

- **Pure Modern HTML5 & CSS3**: Custom design tokens, fluid clamp typography, glassmorphism, responsive grid & flexbox layouts.
- **Vanilla ES6+ JavaScript**: Zero npm dependencies, 100% portable, works out of the box by opening `index.html` in any browser.
- **Canvas 3D Isometric Engine**: Custom lightweight 60 FPS mathematical projection engine with ambient lighting, depth sorting, and particle physics.
- **Web Audio API**: Real-time synthesized telephone ringtones for the fake call simulator.
